# Code of Conduct / Código de conducta

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Este proyecto sigue el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## In short / En resumen

We want a friendly, welcoming project for everyone, whatever their experience, origin, gender, age, language or
background. / Queremos un proyecto amable y acogedor para todo el mundo, sea cual sea su experiencia, origen, género,
edad, idioma o trayectoria.

- Be kind and patient, especially with newcomers. / Sé amable y paciente, sobre todo con quien empieza.
- Criticise ideas and code, never people. / Critica ideas y código, nunca a las personas.
- No harassment, insults, discriminatory language or sharing other people's private information.
  / Nada de acoso, insultos, lenguaje discriminatorio ni publicar datos privados de otras personas.
- English and Spanish are both fine; nobody has to apologise for their language level.
  / Vale el inglés y el español; nadie tiene que disculparse por su nivel de idioma.

## Reporting / Cómo avisar

If something happens, contact the maintainers privately through GitHub (**Security → Report a vulnerability** also
works for conduct reports) or by a private message to a maintainer. Reports are handled confidentially.
Maintainers may remove comments, commits or contributions, and temporarily or permanently ban anyone who breaks these
rules.

Si pasa algo, escribe en privado a los mantenedores por GitHub (**Security → Report a vulnerability** también sirve
para esto) o con un mensaje privado a un mantenedor. Se trata con confidencialidad. Los mantenedores pueden borrar
comentarios, commits o aportaciones, y expulsar temporal o definitivamente a quien no cumpla estas normas.
